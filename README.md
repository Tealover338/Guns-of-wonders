# Guns of Wonders

Автор: **Danila Podpivas**. Minecraft **26.2**, Forge **65.1.0**, Java **25**.

27 предметов оружия находятся в общей вкладке Guns of Wonders. Восемь вариантов
Glock используют разные текстуры исходного проекта `glocki.bbmodel`.
`ming_lava.bbmodel` использует вторую, лавовую текстуру `ming.bbmodel`.
Это самостоятельный мод: устанавливать TACZ не требуется.

## Текущий этап

Отображение оружия в руках, в инвентаре, на земле и от третьего лица.
От первого лица используются руки модели со скином игрока и idle-анимация.
От третьего лица используются настоящие руки персонажа в позе удержания оружия;
дополнительные руки из Blockbench не рисуются. Положение, поворот и ширина рук берутся из той же модели, что от первого лица. Поза фиксируется после обычных анимаций: голова, ходьба и покачивание её не меняют. Рукава и броня следуют этой позе.
Стрельба, урон, прицеливание, доставание и перезарядка пока не реализованы.

## Работа в Blockbench

Модели остаются в формате Generic Model, чтобы сохранить произвольные углы кубов.
`root` объединяет оружие и руки. `gun_and_righthand` содержит оружие и правую руку,
`mag_and_lefthand` — левую. Исходные группы деталей оружия сохранены.
Центры верхних граней кубов `right_arm` и `left_arm` задают точки хвата. Экспорт сохраняет их положение и оси с учётом поворотов кубов и всех родительских групп.
`camera` задаёт положение камеры
первого лица, смотрящей вдоль отрицательной оси Z. `idle_view` — её ориентир,
`iron_view` — заготовка для будущего прицеливания.
Текстура рук в Blockbench служит для предпросмотра, в игре подставляется скин игрока.
Кисть находится у точки хвата, а плечо направлено к игроку.
`glocki.bbmodel` сохранён как исходный шаблон; для игры используются отдельные
`glock_*.bbmodel`, которые экспортируются в восемь предметов.

Idle длится 4 секунды. Сейчас проигрыватель читает линейные ключи перемещения
корневой кости `root`. Новые каналы вращения и анимации отдельных деталей потребуют
расширения проигрывателя; одно добавление reload/fire в Blockbench их не подключает.

После изменения моделей выполните из папки проекта:

```powershell
python tools/export_models.py D:\BlockbenchModels\guns
.\gradlew.bat build
```

Экспортёр обновляет игровые ресурсы, не меняя ваши bbmodel-файлы.
Для изменения положения камеры переместите начало группы `camera` и сам объект камеры.
Для проверки игры выполните `.\gradlew.bat runClient` с Java 25 в JAVA_HOME.
Готовый мод находится в `build/libs/gunsofwonders-1.0.0.jar`.

## Проверка в игре

Создайте творческий мир и откройте вкладку Guns of Wonders. Проверьте каждое оружие
от первого лица, клавишей F5, в левой руке, на земле и в рамке.
Команда для получения: `/give @s gunsofwonders:glock_amethyst`.
Список идентификаторов: `model-catalog.json`.

Идея подачи оружия вдохновлена https://github.com/MCModderAnchor/TACZ.
Исходный код и оружейные ассеты TACZ не включены в этот мод.
